open-crm-cpq is the production CRM/CPQ platform (Drools execute, quotes, CRM UI, gateway). pricing-ai-rules-service (/home/username01/MyCode/pricing-ai-rules-service) remains a Drools+AI specialist: richer agent catalog, MCP clients, rule pipeline, and RL experiment services. After CPQ Waves 1–3, core AI rule-ops (create / modify / evaluate / optimize / performance / experiments) are ported into CPQ behind flags — MCP and most business-domain agents are not.

  1. CPQ wins lifecycle: execute/simulate, rule-set activate, ARR/TCV/ACV waterfall, quotes, CRM, approvals.
  2. Price-Drools wins depth: 17 /v1/agents/* controllers, Sequential/Context7/Puppeteer MCP, prompt-variant pipeline, sports pricing.
  3. Shared surface now: /api/v1/ai/workflow/** and experiment APIs exist in CPQ (ai-service); PD keeps in-process RL + richer performance apply/test paths.
  4. Do not merge PD as a 12th runtime; harvest into pricing-service / ai-service per docs/plans/00-harvest-index.md.
