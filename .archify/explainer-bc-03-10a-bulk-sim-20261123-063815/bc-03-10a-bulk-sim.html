How does a bulk run move?

Diagram structure
  • Pricing admin admin
  • BulkSimulatorComponent ui
  • PricingExecutionService (FE) svc
  • API gateway :8080 gw
  • pricing-service :8082 pricing
  • admin → ui · Paste ≥2 PricingContext JSON (client validates)
  • ui → svc · simulateBulk({ contexts })
  • svc → gw · POST /api/v1/pricing/simulate/bulk
  • gw → pricing · Forward (simulate each, no audit)
  • pricing → svc · BulkPricingSimulationResponse
  • svc → ui · results[] + counts
  • ui → admin · Summary chips + DataTable rows
  1. Paste ≥2 PricingContext JSON (client validates) ↗

    Admin pastes array or { "contexts": [...] }; UI blocks bad JSON or fewer than two.

  2. POST /api/v1/pricing/simulate/bulk ↗

    One request; gateway routes to pricing-service.

  3. Forward (simulate each, no audit) ↗

    Service runs each context without persisting audit.

  4. Summary chips + DataTable rows ↗

    Show success/fail per row; keep partial failures.
