## 2024-05-18 - Prevent XSS/RCE in dynamic expression evaluation using sval
**Vulnerability:** The application was using `new Function()` to dynamically evaluate expressions from Frappe's `depends_on` functionality (e.g., `eval:doc.age > 18`). This allowed unsanitized code execution within the Vue application context, posing a critical Remote Code Execution (RCE) / Cross-Site Scripting (XSS) risk.
**Learning:** Dynamic code evaluation is sometimes required for form dependencies, but relying on native `eval` or `new Function` escapes the Vue context and directly exposes the application to arbitrary JavaScript execution by maliciously crafted form schemas.
**Prevention:** Always use a sandboxed JavaScript interpreter (like `sval`) when dynamic evaluation is necessary. The interpreter must not expose unsafe globals (`window`, `document`) and should be tightly constrained by injecting only explicitly required properties (e.g., `Math`, `JSON`, `Date`) via the `interpreter.import()` method.
