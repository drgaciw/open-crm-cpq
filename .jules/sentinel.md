## 2024-05-07 - [Remove Dynamic Table Concatenation]
**Vulnerability:** Found `frappe.db.sql(f"SELECT ... FROM tab{doctype} ...")` patterns where table names were concatenated dynamically using f-strings. This pattern was correctly flagged as risky by `ast-grep` rules.
**Learning:** Even if the dynamically injected variable (like `doctype`) is pre-validated against a strict hardcoded allowlist (`{"CRM Deal", "CRM Lead"}`), relying on string concatenation for table names introduces an architectural anti-pattern for SQL injection prevention and violates automated structural checks (`ast-grep`).
**Prevention:** Always use explicit, hardcoded strings for SQL query structure (tables, columns) inside conditional logic (`if doctype == "CRM Deal": query = "SELECT ... FROM \`tabCRM Deal\`" ...`) instead of injecting variables, fully isolating structural syntax from dynamic values.
