## Recorded implementation decisions

R3 uses (subscription_id, accepted_line_uuid, sequence) identity so multiple lines can each have period 1. Legacy backfill keeps an explicitly aggregate rate with known MRR/ARR and absent quantity/unit facts; it invents no unit price. Legacy unit-rate renewal fails with an explicit actionable error until a commercial rate is supplied. ApplyRamp runs only for ACTIVE subscriptions; suspended/pending subscriptions retain unapplied periods for catch-up on activation, while cancelled/expired subscriptions do not advance. Accepted event stays version 1 with additive optional fields; existing consumers/tolerance tests must pass.

R4 effective credit is min(round2(bookValue * 0.30), decliningLineTCV, decliningFirstPeriodAmount); unused credit is not carried or transferred. Credit is a one-time amount adjustment: subtract it from first period amount, TCV and term-years ACV while preserving recurring unit/monthly rates and ARR/exit ARR. This is an explicit narrow migration-credit exception to ADR-023 D-02's ordinary periodAmount = netMonthly * months identity. Gross amount, effective/unused credit and adjusted amount must remain auditable and survive the persisted accepted snapshot; no runtime code may assume adjusted amount always equals recurring rate times months.

R4 customer-specific pair/window/book-value inputs use typed validated request metadata; authoritative pricing product data validates roles/types. Root's additional quote handoff must persist and forward that input and include it in approval fingerprint/staleness. Quote ownership is scheduled serially against R3, not edited concurrently. R4's exclusive allowlist is extended narrowly to PeriodGovernance.evaluate and associated tests; MetricsCalculator should remain unchanged unless a new impact-reviewed need appears.

These clarifications are owner-delegated implementation choices recorded before coding, not reports of finance or sales-ops approval. The current accepted ADR/sprint holds remain: no subscriptions UI, Jev activation, Activities, NgRx, dual-read default flip, usage tiers, credit draw-down, order orchestration or production deployment.

### Cross-lane priced-period contract

Reserve additive optional grossPeriodAmount and migrationCredit on priced-period response/persisted/accepted snapshots for the R4 one-time adjustment. Recurring netMonthly times months yields gross amount; adjusted periodAmount equals gross minus credit, with nonnegative credit bounded by gross. Ordinary periods omit the optional fields and retain their existing identity. Service-owned validators distinguish an authorized first declining period credit from corruption; no common-library validator or repricing from authored rates is introduced. Root coordinates these quote/common view changes serially with the R3 producer lane, and R4 owns only the pricing output and policy arithmetic.
